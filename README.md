# Pakistan Live Weather Web GIS

Assignment No. 2: API-Based Web GIS Application (Dept. of Meteorology, COMSATS University Islamabad)

**Live demo:** https://talharasool1.github.io/pakistan-weather-webgis/

## About
A Leaflet web map that fetches current weather for 16 cities of Pakistan using `fetch()` and shows it as temperature markers with popups.

## Features
- Live data from the Open-Meteo Forecast API (no API key)
- Popup with condition, temperature, feels-like, humidity, wind, pressure, precipitation
- City search and temperature filter (cold / mild / hot)
- Click anywhere on the map to get weather for that point
- Loading message, error handling and Refresh button
